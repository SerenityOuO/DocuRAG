# JD Evidence Matrix

本文件對照常見 AI Software Engineer / AI Application Engineer / RAG Engineer / LLMOps JD 能力，整理 DocuRAG 目前可展示、可驗證與仍需誠實說明的地方。

狀態定義：

- `completed`：已在主線 release sync，並有測試、smoke、文件或 artifact 可驗證。
- `demo-safe`：可本機展示，但不是 production-grade runtime。
- `research-only`：只作研究證據或樣板，不接 production runtime。
- `skip-safe`：外部 runtime 不可用時會產出明確 skip / fallback，而不是假裝成功。
- `future backlog`：已定義邊界或後續方向，但本專案目前不宣稱完成。
- `not covered`：刻意不做或尚未規劃成可執行 ticket。

## Gap Summary

- `not covered`：production SSO / OAuth / MFA、enterprise secret manager、managed production database、production alerting / incident workflow、production autoscaling、multi-cluster K8s、real NPU profiling、model registry、full LLM-as-judge eval platform、production annotation platform。
- `future backlog`：gRPC proto / service mesh、durable JetStream worker、production indexing queue、Redis session rotation、formal audit retention、production inference gateway routing / quota。
- `research-only`：SFT / synthetic data / embedding tuning artifacts、hardware / KV cache interpretation、observability dashboard evidence skeleton。
- `demo-safe`：OCR / VLM parser、Qdrant indexing、Redis / NATS worker, K8s baseline, vLLM benchmark smoke。
- `completed`：FastAPI / Vue core app、RAG eval metrics、Agent trace / governance, Phase 44 field QA loop, repeatable backend / frontend validation.
